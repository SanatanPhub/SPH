# Sanatan Pooja Hub

E-commerce website for authentic spiritual products and consultation services.

## Tech Stack

- React + Vite
- Tailwind CSS
- Supabase (backend)
- Vercel (hosting)

## Setup

```bash
npm install
cp .env.example .env  # Add your Supabase credentials
npm run dev
```

## Deploy

Push to GitHub and connect to Vercel. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` as environment variables.
